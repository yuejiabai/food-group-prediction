# Project Context

This repository is a portfolio-oriented presentation of a COMP4702 Machine Learning assignment.

The original report has been retained in the `report/` folder, with the student ID
removed from the public-facing copy. The figures in `results/` were extracted from
the submitted report so the main experimental findings are visible directly from
the repository README.

No additional experimental results have been invented for this portfolio version.
The metrics, dataset sizes, model choices, preprocessing decisions, and conclusions
presented here come from the submitted report.

The full executable source code was not included in the materials used to build
this portfolio package, so this package does not claim to provide a fully
reproducible code release. If the original training script or notebook is available,
it can be added later under a `src/` directory.
